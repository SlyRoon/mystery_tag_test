# mystery_tag_test

Майбутній сервіс приймання постбеків від рекламної мережі та передавання нових подій до API партнера. Заплановані технології: PHP 8.x, MySQL, Redis і Docker.

Зараз у публічному репозиторії лише початкові файли. Застосунок, Docker-конфігурація та інструкції запуску ще не додані. Після реалізації тут з’являться приклади HTTP-запитів, опис дедуплікації та повторних спроб, а також послідовність діагностики недоставлених подій.
